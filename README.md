# 💈 Tu Templo | Barber Shop

**Tu Templo** es más que una barbería: es un espacio donde el estilo, la elegancia y el cuidado personal se encuentran para ofrecer una experiencia única.

Cada detalle está pensado para transmitir identidad, profesionalismo y excelencia.

## 🌐 Sitio web

[Visitar Tu Templo](https://nexowebpy.github.io/TuTemplo/)

## ✨ Características

- Diseño premium y moderno.
- Identidad visual negro y dorado.
- Diseño responsive para dispositivos móviles.
- Presentación de la barbería y su historia.
- Galería visual.
- Experiencia de navegación personalizada.
- Optimización básica para buscadores.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- GitHub Pages
