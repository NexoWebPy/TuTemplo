# Contributing

Gracias por tu interés en contribuir a Tu Templo.

## Lineamientos

Toda contribución debe respetar:

- La identidad visual de Tu Templo.
- La estética premium negro y dorado.
- La experiencia de usuario.
- La compatibilidad responsive.
- La accesibilidad del sitio.

## Cómo contribuir

1. Crear una rama para los cambios.
2. Realizar modificaciones claras y organizadas.
3. Verificar el funcionamiento en diferentes dispositivos.
4. Comprobar enlaces e imágenes.
5. Enviar un Pull Request explicando los cambios.

## Código

Se recomienda:

- HTML semántico.
- CSS organizado.
- JavaScript limpio.
- Código reutilizable.
- Optimización de imágenes.
- Buenas prácticas de accesibilidad.

## Seguridad

No incluir credenciales, información privada ni
configuraciones de servidores en las contribuciones.

Gracias por ayudar a mejorar el proyecto.
